## Study Overview

This study evaluates the trade-off between nonlinear predictive accuracy and computational inference speed when surrogate-modeling urban surface runoff generated in the **EPA Storm Water Management Model (SWMM)**:

- **Synthetic SWMM Benchmark Dataset (`dataset.xlsx`):** Generated by sweeping physical and hydrodynamic subcatchment parameters in EPA SWMM (`137,633` raw parameter combinations; `103,073` valid non-zero runoff records after filtering `34,560` degenerate zero-runoff boundary cases).
- **Train / Test Partition:** Random `80% / 20%` split (`random_state=0`) yielding `82,458` training samples and `20,615` holdout test samples across 8 input predictors.
- **Evaluated Surrogate Architectures:**
  1. **Artificial Neural Network (`ANN.ipynb`):** Feedforward sequential neural network in TensorFlow/Keras with an input Z-score normalization layer followed by three hidden `Dense` layers (`8 -> 8 -> 8` neurons, ReLU activation) and a linear/ReLU output unit (`234` total parameters), trained with Adam and early stopping (`patience=2`).
  2. **Elastic Net Regression (`ElasticNet.ipynb`):** Regularized linear regression model combining $L_1$ (Lasso) and $L_2$ (Ridge) penalties (`alpha=0.01`, `l1_ratio=0.2`) fitted on Z-score standardized features (`StandardScaler`).
- **Central Finding (Accuracy vs. Inference Latency Trade-Off):**
  - The **ANN** captures nonlinear interactions between imperviousness, flow path width, slope, and roughness, achieving near-exact surrogate fidelity (**$R^2 = 0.995$**, **$\text{RMSE} = 0.109\text{ m}^3/\text{s}$**, **Index of Agreement $d = 0.999$**, **Scatter Index $\text{SI} = 0.030$**) at a batch inference latency of **$1.344\text{ s}$** across the `20,615` test samples.
  - **Elastic Net** executes batch inference in **$0.003\text{ s}$** (~450x faster than Keras batch evaluation) and offers direct coefficient interpretability, but its linear functional form underfits low-flow and strongly nonlinear regimes (**$R^2 = 0.550$**, **$\text{RMSE} = 1.017\text{ m}^3/\text{s}$**, **$d = 0.837$**, **$\text{SI} = 0.277$**).

## Quantitative Benchmark Results

Metrics evaluated on the holdout test split ($N = 20,615$ samples):

| Metric | Artificial Neural Network (ANN) | Elastic Net (`alpha=0.01, l1_ratio=0.2`) |
| :--- | :---: | :---: |
| **Coefficient of Determination ($R^2$)** | **0.995** | 0.550 |
| **Mean Squared Error ($\text{MSE}$)** | **0.012** | 1.035 |
| **Root Mean Squared Error ($\text{RMSE}$)** | **0.109** | 1.017 |
| **Mean Absolute Error ($\text{MAE}$)** | **0.075** | 0.835 |
| **Index of Agreement ($d$)** | **0.999** | 0.837 |
| **Scatter Index ($\text{SI}$)** | **0.030** | 0.277 |
| **Batch Inference Time ($N = 20,615$)** | 1.344 s | **0.003 s** |

## Input Feature Space

Each sample in `dataset.xlsx` represents an EPA SWMM simulation parameterized by 8 subcatchment attributes and 1 target response variable:

| Column | SWMM Section | Unit | Type | Description |
| :--- | :--- | :---: | :---: | :--- |
| `PercImperv` | `[SUBCATCHMENTS]` | `%` | `int8` | Percentage of impervious catchment area (`1` to `100`) |
| `Width` | `[SUBCATCHMENTS]` | `m` | `int16` | Characteristic width of the overland flow path (`1` to `1000`) |
| `PercSlope` | `[SUBCATCHMENTS]` | `%` | `int8` | Average surface slope (`1` to `100`) |
| `N-Imperv` | `[SUBAREAS]` | `-` | `float32` | Manning's roughness coefficient for impervious area (`0.015` to `0.800`) |
| `N-Perv` | `[SUBAREAS]` | `-` | `float32` | Manning's roughness coefficient for pervious area (`0.015` to `0.800`) |
| `S-Imperv` | `[SUBAREAS]` | `mm` | `float32` | Depression storage depth on impervious area (`0.05` to `0.30`) |
| `S-Perv` | `[SUBAREAS]` | `mm` | `float32` | Depression storage depth on pervious area (`0.05` to `0.30`) |
| `PctZero` | `[SUBAREAS]` | `%` | `int8` | Percentage of impervious area with zero depression storage (`10` to `100`) |
| `Runoff` (`TotalRunoffMG`) | `[REPORT]` | $\text{m}^3/\text{s}$ | `float64` | **Target variable:** simulated surface runoff volume |

## Reproducibility & Usage

### 1. Environment Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Running the Notebooks

Launch Jupyter Lab or Jupyter Notebook from the repository root (ensuring `dataset.xlsx` is in the working directory):

```bash
jupyter lab ANN.ipynb ElasticNet.ipynb
```

### 3. Regenerating the SWMM Dataset (Optional)

To run a custom subcatchment parameter sweep against an EPA SWMM `.inp` template:

```bash
python analyse_code.py --inp example_copy.inp --output dataset.xlsx --subcatchment S1
```
